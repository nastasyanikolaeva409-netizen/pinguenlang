# пингвинёнок — сайт для изучения языков

Полностью перевёрстанная версия сайта с новой концепцией «пингвинёнок»: чистый HTML5, CSS3 и vanilla JavaScript. Единственная внешняя зависимость — шрифт Nunito из Google Fonts.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер (рекомендуется, чтобы корректно работали относительные пути и `localStorage`):

```bash
python -m http.server 8000
# затем http://localhost:8000
```

## Структура

```
index.html          — главная страница
lessons.html        — SPA уроков: онбординг, мини-тест, урок, результат
css/styles.css      — дизайн-система, компоненты, адаптивность, тёмная тема
js/i18n.js          — движок локализации: t(), apply(), setLang(), onChange()
js/locales/         — шесть словарей по 239 ключей
js/script.js        — меню, снег, динамические блоки и вся интерактивность
js/lessons.js       — данные уроков, онбординг, тест и сохранение прогресса
images/
  penguin-mascot.png  — маскот с прозрачным фоном
  penguin-icon.png    — иконка-голова для логотипа (прозрачный фон)
  favicon.png         — favicon 128×128
```

## Дизайн-система

Палитра задана в `:root` (и переопределена для `prefers-color-scheme: dark`):

| Переменная | Значение | Назначение |
| --- | --- | --- |
| `--primary` | `#0EA5E9` | основной синий |
| `--primary-shadow` | `#0369A1` | тень 3D-кнопок |
| `--dark-blue` | `#1E3A5F` | заголовки и логотип |
| `--accent` | `#FB923C` | оранжевый акцент |
| `--bg-section` | `#F0F9FF` | фон чередующихся секций |
| `--bg-main` | `#FFFFFF` | основной фон |
| `--text-main` | `#334155` | основной текст |
| `--text-muted` | `#64748B` | вторичный текст |
| `--border-color` | `#E0F2FE` | границы и плашки |

## Возможности

- **Шапка**: логотип, навигация, переключатель языка, кнопка «Начать бесплатно» (на десктопе), мобильное бургер-меню с выезжающей панелью.
- **Переводы**: 6 языков (Русский, English, Deutsch, Français, Español, 中文), по 239 ключей в каждом. Переведены все оставшиеся секции, meta, `aria`-атрибуты и динамические блоки. Выбор сохраняется в `localStorage` под ключом `penguin-language`.
- **Hero**: снегопады (меньше на мобильных, отключаются при `prefers-reduced-motion: reduce`), сугробы, «дышащий» маскот, облачка-реплики, 3D-кнопки.
- **Интерактив**: табы экзаменов, табы аудитории, аккордеон FAQ, переключение языка, компактное форматирование чисел учеников.
- **Уроки**: SPA в `lessons.html` — онбординг с мини-тестом, три первых урока, прогресс-бар, зелёная/красная подсветка ответов и сохранение текущего урока в `localStorage`.
- **Языки**: английский ведёт на `lessons.html`; немецкий, французский, испанский, итальянский и китайский помечены как «В разработке» и визуально приглушены.
- **Доступность**: skip-link, `aria`-атрибуты, фокус-ловушка в меню, управление с клавиатуры, поддержка reduced-motion.

## Замена ресурсов

Пути к изображениям: `images/penguin-mascot.png`, `images/penguin-icon.png`, `images/favicon.png`. Достаточно заменить файлы, сохранив имена, — разметка менять не нужно.

## Примечание

Словари лежат в `js/locales/`, движок — в `js/i18n.js`. Все шесть словарей полные (239 ключей), с корректными формами плюрализации: `one/other` для немецкого, `one/many/other` для французского и испанского, `other` для китайского. Динамические блоки (экзамены, аудитория и количество учеников) перерисовываются при смене языка через `I18N.onChange`.
